How to install (Gmail)
  1. Open Gmail → gear icon (top right) → See all settings.
  2. Scroll down to Signature → Create new → name it "G3".
  3. Come back to this page and click the Copy signature button above.
  4. Click into the Gmail signature box and paste (Ctrl‑V / ⌘V).
  5. Under "Signature defaults," set it for new emails and replies (optional).
  6. Scroll to the bottom → Save Changes.
